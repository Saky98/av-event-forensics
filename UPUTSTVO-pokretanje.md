# Kako pokrenuti

Server za razvoj (potreban samo Node.js 18+):

```bash
git clone https://github.com/Saky98/av-event-forensics.git
cd av-event-forensics
npm install
npm run dev
```

Otvori: **http://localhost:5173/**

Učitaj demo snimak: `storage/Town02_truck_collision.mcap` (i `storage/compromised/...` za prikaz hash/chain).

Produkcija (opciono): `npm run build` pa `npm run preview`.
